# Music player tracks

The page ships with three quiet synthesized WAV placeholders so the player works on first visit. Replace these files with your own audio, keeping the filenames or updating the track list in `src/App.tsx`:

- `blue-hour.wav`
- `soft-focus.wav`
- `after-the-rain.wav`

The player reads these files from `/music` and supports WAV or browser-compatible MP3/OGG files.
